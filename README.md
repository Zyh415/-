# 🎁 青铜宝箱 - 在线抽奖系统

一个现代化的、支持多人同时在线参与的Web抽奖系统。用户可以通过填写姓名和邮箱，点击按钮开启虚拟宝箱进行抽奖。

## ✨ 主要功能

### 🎯 抽奖功能
- **用户验证**：抽奖前需输入姓名和邮箱
- **双奖品设置**：
  - 🏅 起点岛勋章（100% 获奖概率）- 所有参与者都会获得
  - ☕ 咖啡券（10% 获奖概率）- 1/10 的概率额外获得
- **精美动画**：宝箱开启、金币飞舞等视觉效果
- **实时反馈**：即时显示抽奖结果

### 📊 记录管理
- **实时更新**：查看所有用户的抽奖情况
- **统计面板**：显示总参与人数、各奖品获奖人数
- **高级筛选**：
  - 按姓名/邮箱搜索
  - 按获奖类型筛选
- **数据导出**：一键导出为 CSV 文件
- **数据管理**：支持清空所有记录

## 🛠️ 技术栈

- **HTML5** - 页面结构
- **CSS3** - 响应式设计和动画效果
- **Vanilla JavaScript** - 核心业务逻辑
- **localStorage** - 数据持久化存储

## 📝 使用说明

### 参与抽奖
1. 点击导航栏的"抽奖"按钮
2. 填写姓名和邮箱（都是必填项）
3. 点击"开始抽奖"按钮
4. 观看宝箱动画
5. 查看您的抽奖结果

### 查看抽奖记录
1. 点击导航栏的"抽奖记录"按钮
2. 查看统计数据（总人数、各奖品获奖人数）
3. 使用搜索框按姓名或邮箱搜索
4. 使用下拉菜单按奖品类型筛选
5. 点击"导出为 CSV"保存数据
6. 点击"清空记录"删除所有数据

## 🎨 自定义指南

### 修改奖品
编辑 `app.js` 中的 `PRIZES` 对象：

```javascript
const PRIZES = {
    medal: {
        name: '您的奖品名称1',
        icon: '🏅',
        description: '奖品描述',
        probability: 1.0
    },
    coffee: {
        name: '您的奖品名称2',
        icon: '☕',
        description: '奖品描述',
        probability: 0.1
    }
};
```

### 修改概率
修改 `probability` 字段（0-1之间，1表示100%）：
- `0.1` = 10% 获奖概率
- `0.5` = 50% 获奖概率
- `1.0` = 100% 获奖概率

### 修改颜色主题
编辑 `styles.css` 中的 CSS 变量：

```css
:root {
    --primary-color: #d4af37;      /* 主色调 */
    --secondary-color: #8b7355;    /* 副色调 */
    --success-color: #4caf50;      /* 成功色 */
    --error-color: #f44336;        /* 错误色 */
}
```

所有数据都存储在浏览器的 `localStorage` 中：

- **持久化**：浏览器缓存清空后数据会丢失
- **安全性**：建议定期备份重要数据

## 🐛 故障排除

### 数据没有保存
- 检查浏览器是否启用了本地存储
- 尝试清除浏览器缓存后重新开始
- 检查浏览器控制台是否有错误信息

### 动画不显示
- 检查浏览器是否禁用了CSS动画
- 尝试更新浏览器到最新版本
- 检查GPU加速是否启用

### 邮箱验证失败
- 确保邮箱格式正确（example@domain.com）
- 检查是否有多余的空格
